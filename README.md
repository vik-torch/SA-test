ТЕСТОВОЕ ЗАДАНИЕ Nº1 — Структура спецификации (до 20 минут)

Подготовьте структуру (оглавление) типовой спецификации требований (SRS) для нового модуля «Личный кабинет» интернет-магазина.
Требуется:
1. Оглавление документа с разделами и подразделами (не менее 10 разделов).
2. Для каждого раздела — одно предложение, описывающее его содержание.
3. Обязательно включить: бизнес-цели, функциональные требования, нефункциональные требования (производительность, безопасность, доступность). описание ролей пользователей, интеграции, ограничения и допущения, глоссарий
4. Указать, какие диаграммы (BPMN/UML) должны сопровождать каждый раздел.
Время: до 20 минут. Инструменты: текстовый редактор / бумага.

ТЕСТОВОЕ ЗАДАНИЕ Nº2 — Проектирование (до 40 минут)

Спроектируйте процесс регистрации и аутентификации пользователя в мобильном приложении интернет-магазина (email + пароль, вход через Google/Apple, восстановление пароля).
Требуется:
1. BPMN-диаграмма процесса регистрации (happy path + обработка ошибок: email уже существует, слабый пароль).
2. UML Sequence Diagram: Мобильное приложение - Backend AP| → База данных → Email-сервис
3. Список из 5-7 функциональных и 3 нефункциональных требований.
4. Acceptance Criteria для одной User Story в формате Given/When/Then.
Время: до 40 минут. Инструменты: бумага/Draw.io/PlantUML.
